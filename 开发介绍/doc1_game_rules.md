# 指尖博弈 — 游戏规则与角色介绍

## 一、基础规则

### 核心机制

每位玩家有**左手**和**右手**两个数字（0-9）。轮到你时：

1. **选择自己一只手**
2. **点击对方一只手**
3. 两数相加取余10，结果更新到你选的手上

```
示例：我的左手=3，对方右手=5 → 3+5=8 → 我的左手变为8
示例：我的右手=7，对方左手=6 → 7+6=13 → 13%10=3 → 我的右手变为3
```

**限制：不能碰对方数字为0的手。**

行动结束后自动切换到下一位玩家。

---

### 组合触发（优先级从高到低）

#### 双子星（两手相同）

| 组合 | 效果 |
|------|------|
| [1,1] | 无敌2回合（免疫物理/法术，真伤可穿透） |
| [2,2]/[3,3] | 30点物理护盾，持续3回合 |
| [4,4] | 获得2次伤害翻倍 |
| [5,5] | 获得2层反弹盾 |
| [6,6] | 回复90血 |
| [7,7] | 30物伤+3层中毒 |
| [8,8] | 获得2次额外行动 |
| [9,9] | 40×2^N物伤（N=场上所有手中3的倍数数量，0不算） |
| [0,0] | 对敌方造成150点真实伤害 |

#### 0组合（有一只手是0）

| 另一只手 | 效果 |
|---------|------|
| 1/5/8/9 | 40点物理伤害 |
| 2/3 | 20点物理护盾，3回合 |
| 4/6 | 回复30血 |
| 7 | 10物伤+1层中毒 |
| 0 | 150点真实伤害 |

#### 单手特效（新变出才触发）

- **单手6**：回复30血
- **单手7**（忍者专属）：给对方附加1层中毒
- **单手2/3**（小乔专属）：获得20点护盾（3回合）

---

### 0的特殊规则

- 碰出0后，该手启动**倒计时**（默认2回合）
- 倒计时归零时，必须用那只0的手行动（强制）
- 通过碰别人让0变成其他数字可解除限制
- **双手全为0时立即死亡**
- 对方双手全为0时，你本回合跳过，但状态照常结算

---

### 伤害类型

| 类型 | 说明 |
|------|------|
| 物理伤害 | 可被物理盾/物法盾抵挡，可被物免减伤 |
| 法术伤害 | 可被法术盾/物法盾抵挡 |
| 真实伤害 | 穿透所有护盾和减伤，无敌也无法免疫 |

---

### 状态系统

#### 护盾
- 类型：物理盾、法术盾、物法盾（两种都挡）、真实盾
- 剩余回合短的优先消耗
- 每回合流逝一次持续时间

#### 中毒
- 每层中毒 = 回合结束时受10点**法术伤害**（法盾可抵挡）
- **回复（RECOVERY）类回血**可解毒：每20点回血解1层
- 回血量不足时，剩余存入溢出池，下次累计

#### 回血类型

| 类型 | 解毒 | 被大乔抢 | 更新孙悟空y |
|------|------|---------|------------|
| 回复（RECOVERY） | ✅ | ✅ | ✅ |
| 补给（SUPPLY） | ❌ | ❌ | ❌ |

#### 冰冻
- 下一个自己的行动回合完全跳过
- 状态（中毒/护盾/倒计时）照常结算

#### 无敌
- 免疫物理和法术伤害
- 真实伤害可穿透

---

### 大回合
所有玩家各行动一次 = 一个大回合。部分技能（如藏师蛋糕上限、张飞怒气上限）按大回合计算。

## 二、角色介绍

> 注：所有角色血量已翻倍（相对原始设计值）。

### 🌸 小乔（半肉 | HP: 360）

**技能：**
1. 物理伤害×1.5，所有回血×1.5
2. 造成物伤时，**补给**等量血量；回血时对敌方造成等量物理伤害
3. 0可停留3回合（比普通角色多一回合）
4. 所有护盾升级为物法盾，厚度×1.5，持续+1回合
5. 单手变为2或3时（新变出才触发），获得20点护盾（经升级后变物法盾）

---

### 🛡️ 藏师（坦克 | HP: 660）

**技能：**
1. 受到物理伤害减半
2. 受到物伤后，反弹实际扣血量的50%给攻击者（物理伤害）
3. 自身回复量×2.5；获得护盾厚度×2；获得物理盾时同时获得一半厚度的法术盾
4. 🍓草莓蛋糕：自身回血/获盾/造伤时+1蛋糕（每大回合上限8个）；消耗3个蛋糕 → 对目标造成10法伤+自身回复10血

---

### ⚡ 法师（刺杀 | HP: 160）

**技能：**
1. 触发0组合时：物理伤害翻倍 + 额外45法伤 + 给目标附加1层雷霆之怒
2. 🌩️雷霆之怒（持续3回合）：持有者回合结束时，按双手偶数（2/4/6/8）个数触发伤害，起步40，每次触发+15（全场共享计数器，buff全消才重置为40）
3. 雷霆伤害时，法师获得等量**补给**

---

### 🐒 孙悟空（半肉 | HP: 260）

**技能：**
1. 初始增益：x=30（物伤增益），y=15（回血增益）
2. 场上任何人造成物伤时更新x；任何人回血时更新y（均为输出端值，不含目标减伤）
3. 自身造成物伤时额外造成x点物伤；自身回血时额外回复y点血（各自更新x/y，不套娃）
4. [0,2]改为：70法伤 + 回复70血（RECOVERY，会被大乔抢）+ 冻结对方1回合；同一次0增益最多使用3次，不消耗0使用次数

---

### 🌸 大乔（天后 | HP: 120）

**技能：**
1. 主动抢夺全场RECOVERY回血的50%（5秒内可选择，不抢则放弃；不抢自己）
2. 造成物伤时，回复（RECOVERY）实际扣血量的50%
3. HP突破300后可进化为神大乔（扣300血）：物伤×1.5，受物伤-1/4，每次抢夺额外+10血，废弃复活甲
4. 复活甲：HP归零时触发，无敌2回合，期满以50血复活（仅限一次，进化后废弃）

---

### 🥷 忍者（半肉 | HP: 300）

**技能：**
1. 造成物伤时，额外附加50%法伤（基于输出值，不受目标减伤影响），回复法伤**实际扣血量**（SUPPLY）
2. 新变出7时：给对方附加1层中毒（[x,7]被动）
3. 场上非忍者单位因中毒扣血时，忍者获得等量**补给**；每解一层毒，忍者回复20血（SUPPLY）
4. 场上非忍者单位总毒层数N，提供物法减伤：前3层各17%（最高51%），超过后每层+9%（最高78%）

**毒层与忍者伤害的关系：**
- 单7攻击（如[1,7]）：onAfterDealtDamage 1层 + [x,7]被动1层 = **共1层**（被动替代普通毒，不叠加）
- [0,7]：[0,7]组合自带1层 + [x,7]被动1层 = **共2层**
- [7,7]：双子星自带3层 + [x,7]被动1层 = **共4层**

---

### 🐗 张飞（坦克 | HP: 560）

**技能：**
1. 回合结束时补给10血（狂暴时20血）
2. 受到物伤时免疫"双手差值×10"的物伤（狂暴时翻倍）
3. 三种模态（随时切换，默认①）：①物伤×1.5；②物伤×0.75打两人（1v1禁用）；③造伤后回复（RECOVERY）实际物伤的一半
4. 怒气系统：每次回血/受击/造伤+1怒气（每大回合上限4层，无总上限）。消耗24怒气进入狂暴3回合：0可用3回合，补给翻倍，免伤翻倍，物伤×2（与模态①叠加=×3）

---

### ☯️ 阴阳师（半肉 | HP: 240）

**三种模态（每次轮到自己行动前可切换一次）：**

| 模态 | 输出 | 回血 | 受伤 |
|------|------|------|------|
| 阴 | ×3.5（物伤），回血→等量×3.5物伤 | 回血改为造伤 | 受伤×1.5 |
| 阳 | 造伤→等量×3.5回血 | ×3.5 | 受伤×1.5 |
| 人（默认） | ×0.5 | ×1.5 | 物法免伤1/4 |

**特殊护盾（人→阴/阳时产生）：**
- 厚度 = 25 × 敌人数，每回合 -=10 × 敌人数（物法盾，真伤穿透）
- 切回人：回复护盾当前剩余厚度的血量，护盾保留
- 阴阳直接互切：护盾归零，自身受"原护盾剩余/2"点物伤

## 三、2v2规则

### 队伍与行动顺序
- 4人对战，行动顺序 1→2→3→4
- 1&3一队（HERO），2&4一队（REBEL），交替行动
- 只能碰敌人，不能碰队友

### 阵容选择

开局时每支队伍独立选择阵容：

#### 双半肉流
- 每回合开始前可自由切换"抗伤位"
- 对方只能打到当前抗伤位
- **双半肉加强**（相对坦脆流的补偿）：
  - 抗伤位回血×1.5，护盾持续时间+1回合
  - 物理/法术盾升级为物法盾（本来就是物法盾则厚度×1.5）

#### 坦脆流
- 指定一人为**坦克**，另一人自动为**脆皮**，抗伤位固定不可切换
- 脆皮只能打到对方坦克（坦克死后可打脆皮）
- 坦克可自由选择攻击对方任意存活单位（战场UI右下角显示选择按钮）
- **坦脆流坦克永久加强（开局即生效）**：
  - 所有回复×1.5（与角色自身加成叠乘，如小乔坦克=×1.5×1.5=×2.25）
  - 护盾升级：非物法盾→物法盾+持续+1回合；已是物法盾→厚度×1.5

### 混合阵容规则（双方阵容不同时）
| 攻击方 | 防守方 | 攻击限制 |
|--------|--------|---------|
| 双半肉 | 双半肉 | 只能打对方抗伤位 |
| 双半肉 | 坦脆 | 只能打对方坦克 |
| 坦脆（脆皮） | 任意 | 只能打对方坦克（死后打脆皮/抗伤位） |
| 坦脆（坦克） | 双半肉 | 只能打对方抗伤位 |
| 坦脆（坦克） | 坦脆 | 可自由选择目标 |

### 豁免抗伤规则的特殊技能
以下技能的目标选择**不受抗伤位限制**，可以打到任意存活敌人：
- 孙悟空 [0,2] 大招
- 藏师草莓蛋糕
- 张飞模态②（打两人）

### 帮抗机制
- 队友即将因本次攻击阵亡（且帮抗者自己扛得住），弹窗询问是否帮抗
- 帮抗者承受本次攻击所有输出伤害 × 1.5（走帮抗者自己的减伤/护盾）
- 被帮者完全不受本次伤害（恢复到攻击前状态）
- 若帮抗者承受后也会死亡，弹窗不出现
- 弹窗倒计时10秒，超时视为放弃帮抗

### 反弹规则
- 藏师被动反弹、[5,5]反弹盾：反弹给**直接攻击者**，无视抗伤位
